# Accessible Food Ordering

An accessible food-ordering MVP focused on making restaurant discovery, nutrition details, and allergen information easier to understand. The prototype uses sample restaurant data and simulates the cart, checkout, and order-tracking experience.

## Features

- Browse restaurants and search by restaurant, cuisine, dish, or ingredient.
- View menus with item descriptions, ingredients, dietary tags, and INR prices.
- See each restaurant’s nutrition information status: Verified, Estimated, or Unavailable.
- Review item-level nutrition values where available; estimated values are marked as approximate.
- Set dietary preferences and an allergen profile.
- Receive an allergen warning when an item or selected customization conflicts with the saved profile.
- Customize menu items, adjust quantities, and review itemized cart totals.
- Complete a simulated checkout and follow the order through a simulated status tracker.
- Use accessibility controls for text size, high contrast, and reduced motion, alongside skip navigation and screen-reader announcements.
